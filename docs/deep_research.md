# 深度研究流程(第1层定性归因的 Agentic 升级)

买点扫描器的三层漏斗里,第1层「下跌归因」(这利空5年后还重要吗?)是
**权重最高、最不可纯自动化**的一层。本文件记录把它做成 **deep research** 的流程、
分工与局限。产物示例:`reports/<代码>_deep.md`,汇总见 `reports/_SUMMARY.md`。

## 为什么需要它

早期版本(`examples/13` + `qgent/research/analyst.py`)只给大模型喂了
**~8 条 yfinance 新闻标题 + 十几个指标**,输入太薄,只能产出概括,且大模型
最终买卖标签在多次运行间会漂移(见 [[present-evidence-not-verdict]] 的教训)。
深度研究要解决的是:**用足够厚的数据 + 多步推理,把"错杀 vs 价值毁灭"讲清楚,
并给可证伪的论据**——但仍**不替使用者下买卖判断**。

## 三步流程与分工

```
① 数据采集(可自动化)          ② 联网归因(需 Agent 在环)        ③ 综合(需 Agent 在环)
   yfinance 多期三表/分析师   →   WebSearch/WebFetch 挖           →  多空论证 + 估值博弈 +
   qgent/research/financials.py   "为什么跌"/竞争/催化剂/纪要        催化剂时间线 + 待核实清单
   examples/14_deep_research_data.py                                  → reports/<代码>_deep.md
```

- **① 数据采集** —— **已模块化、可复用**:`fetch_deep_financials(symbol)` 拉年/季三表
  (营收/营业利润/净利/EPS/FCF 的 4 年趋势、债/现金/权益/商誉、分析师目标价、估值比率),
  `format_digest()` 汇成可读/可喂模型的文本块。脚本 `examples/14_deep_research_data.py`。

- **② 联网归因** —— **需 Agent 在环**:用联网搜索逐只挖下跌的**真因**(管理层指引、
  分析师降级理由、竞争格局、催化剂时间线)。yfinance 新闻只有标题+短摘要,远不够;
  必须联网读全文。

- **③ 综合** —— **需 Agent 在环**:把①②整合成结构化报告:业务/为什么跌/三表深挖/
  竞争护城河/多头/空头/估值/催化剂/待核实/决策要点(只列优势与风险,不下买卖判断)。

## 报告结构(每只 _deep.md)

0 一句话 · 1 这是什么公司 · 2 为什么跌(核心) · 3 财务深挖(三表趋势) ·
4 业务与护城河/竞争 · 5 多头(Bull) · 6 空头(Bear) · 7 估值与街面 ·
8 催化剂时间线 · 9 待你核实 · 🧭 决策要点(判断权在你) · 数据来源(链接)

## 关键局限(诚实划线)

- **②③ 目前是「Agent 在环」,不是无人值守脚本**。脚本调外部大模型(如 DeepSeek
  OpenAI 兼容接口)**没有联网浏览能力**;真正的 deep research 依赖 web 访问。
  若要自动化②③,需给脚本接一个**搜索 API**(Serper/Tavily/Bing 等),
  当前未接——属有意识的取舍(深度优先,先把方法跑通)。
- 数据源能到的深度 = **财务面 + 分析师/估值 + 新闻驱动的催化剂分析**;
  拿不到的 = 电话会全文逐字、分部细粒度、竞品一手数据(除非另接源)。
- 大模型/联网结论需**自行复核**;财务数据滞后季报最多 3 个月。
- ⚠️ 全部为研究信号,**非投资建议**。
