# 美股买点扫描器 + 三层分析

> 在「基本面稳的大标的」上做 RSI 超卖择时，并区分「打折的好公司」与「正在崩塌的烂公司（接飞刀）」。

源自 Pine 指标《RSI策略信号 [基本面不会被破坏的大标的]》的买入信号 `buy1`，落地为可扫描 S&P 500 的选股工具，外加自动基本面体检。

---

## 1. 策略哲学

只在**基本面不会崩塌的大标的**上做超跌买入：好公司因「不影响基本面的利空」被错杀时入场，长期持有。
- 不碰新上市、不碰基本面出大问题的标的。
- 典型对象：BTC、可口可乐这类价值稳定的老标的。

核心矛盾：RSI 超卖在**好公司**上是「打折」，在**烂公司**上是「价值毁灭」。技术信号无法区分两者——这正是三层分析要解决的问题。

---

## 2. 买点定义（`examples/11_us_buy_scanner.py`）

与 Pine `buy1` 完全一致，**只看 RSI，不看乖离率**（乖离率仅用于排序/展示）：

```
rsiValue = RSI(close, 6)          # Wilder 平滑
slow     = SMA(rsiValue, 6)       # 慢线
fast     = SMA(slow, 2)           # 快线（对慢线再平滑）
rsi_low  = lowest(slow, 4)        # 慢线近 4 根最低
buy      = (rsi_low < 28) AND crossover(slow, fast)   # 进过超卖区 + 拐头向上
```

- **默认周线**（贴合「长期持有」的低频投资；信号比日线稀疏 7 倍但质量≥日线）。`--daily` 切日线。
- **Universe = S&P 500 成分股**：天然满足「市值大/流动性好/上市久/非仙股」的严格过滤前提。
- 长期均线：周线用 52（≈1年），日线用 250。

### 为什么周线（实证）
| | 日线 | 周线 |
|---|---:|---:|
| 信号/股/12年 | 41 次 | 5.6 次 |
| 1年后 胜率/均值 | 70% / +21% | 71% / +26% |

周线还缓解「信号聚集」陷阱：日线下 2020-03 暴跌一月触发 936 信号（高度重复计数），周线压成 1-2 根，样本更接近独立事件。

## 3. 三层分析（决策漏斗）

技术买点只回答「哪些便宜了」，三层分析回答「哪些值得买」。

### 第 1 层：下跌归因（定性，权重最高，不可自动化）
判断这次下跌**价值动没动**，核心问句「这利空 5 年后还重要吗？」：
- 系统/板块回调、一次性事件 → 好机会
- 结构性恶化（需求被替代、护城河破、监管永久改变）→ 陷阱

扫描器输出**研究清单**辅助人工：行业已知风险提示（如 Packaged Foods → GLP-1 冲击）、营收趋势、待答问题。

### 第 2 层：基本面体检（`qgent/fundamental/health.py`，自动）
`health_report(f, price_history)` → `{verdict, score, flags, kind}`，verdict ∈ `healthy ✅ / review ⚠️ / avoid ❌`。

**两条实质分析路径**（周期股不豁免，只是换尺子）：

- **共同否决（暴雷）**：利息覆盖<2 / 极高杠杆(D/E>400) / 负 FCF+高杠杆 → `avoid`
- **路径 A 非周期股**：营收两季连降 + 利润降更快（毛利压缩）→ `avoid`；否则按 盈利/成长/安全/估值(PE/PB+价值陷阱检测) 打分
- **路径 B 周期股**（Energy/半导体/材料…）：用**周期位置**（价格/营收历史分位）+ **PB 而非 PE** + 资产负债表扛低谷能力打分；营收**跌破历史底部**才 `avoid`

数据缺失只近似降级，**绝不退化为「豁免/甩人工」**。

### 第 3 层：量价质地（自动）
- **放量恐慌 vs 缩量阴跌**：信号那根成交量 / 前 12 根均量（放量=抛售可能出尽；缩量=无人接）
- **乖离率历史分位**：当前乖离在该股自身历史的百分位（越低越极端）

## 4. 用法

```bash
# 周线扫描（默认，推荐），用缓存秒出
.venv/bin/python examples/11_us_buy_scanner.py

# 选项
--daily         # 日线
--weeks N       # 回看 N 根（默认周线 4）
--refresh       # 强制重新下载行情
```

输出：候选按 ✅/⚠️/❌ 分档，每只附 健康分 / 类型(常规/周期) / 量价 / 历史胜率 / 红旗 + 末尾研究清单。

数据缓存在 `.cache/`（行情 4 天复用，基本面 7 天复用），均已 gitignore。

## 6. 已知局限

- **财务数据滞后**季报最多 3 个月，价格领先——第 2 层是安全网，第 1 层定性归因（读电话会/新闻）才抢在价格之前。
- **yfinance `info` 口径/TTM 有坑**且会自相矛盾（如 GIS `totalDebt=0` 却 `debtToEquity=217`），已做交叉校验但非万无一失。
- **历史胜率有「样本聚集」水分**：合并样本里暴跌月重复计数，有效独立样本远小于名义值；单股样本（5–45 个）偏少。
- **评分阈值为经验默认值**，集中定义在 `health.py` 顶部常量，便于调参。
- ⚠️ 全部为研究信号，**非投资建议**。
